# 出力のパターン

レコード内容を Excel / PDF として書き出す帳票系のパターン。

---

## Excel / PDF 帳票

<!-- 画像参照: Manual の Image/web/patterns/output_report.png (ここではコメントアウト) -->

Excel テンプレートを `$Field.Value` / `#LoopRow` のような **Excel.Report.PDF 記法**で書き、現在の Module データ (親フィールド + 明細リスト) を差し込んで Excel/PDF として出力するパターン。請求書・見積書・成績表など定型帳票に。

差し込み記号は、フィールドが `$フィールド名.Value`、モジュールスクリプトのトップレベルで宣言した変数 / 定数が `$変数名` (フィールドと違い `.Value` は付かない)。ドットを含まない `$変数名` は、セルにその記号だけを書いたときに置換される。スクリプトで組み立てた文言や集計値をそのまま帳票に出せる。

デザイナのソリューションエクスプローラーでモジュールを右クリック → **Export Excel Print CheatSheet** を選ぶと、そのモジュールで使える差し込み記号 (フィールド・スクリプト変数 / 定数・明細リストの行) の一覧を Excel に書き出せる。

**標準パターン集の対応**: サイドバー **`出力/帳票 → `ReportSample``**
